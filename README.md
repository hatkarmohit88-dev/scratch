        ** HOW TO USE SCRATCH [Onscreen Annotation Tool] **
        
        1. Open Downloads Folder        
        2. Open "Scratch-Pen-Annotator-Windows.zip" Folder
        3. Open "Start Pen Annotator.bat" File
        4. Select Extract all Files
        5. Go to Downloads Folder Again.
        6. Open the Folder named "Scratch-Pen-Annotator-Windows"
        7. Open the file named "Start Pen Annotator.vbs"
        8. Use the App, from the next time, directly open "Start Pen Annotator.vbs" file.
